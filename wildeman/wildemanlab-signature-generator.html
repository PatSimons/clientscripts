Which button?

Copy signature is the one to use. It copies the finished signature with images and links, ready to paste straight into Gmail, Outlook or Apple Mail as shown below.

Copy HTML is only for tools that ask for HTML code, such as Thunderbird (“Use HTML”), a CRM like HubSpot, or a signature manager. Paste the code there, not into a normal signature box.

Gmail

  1. Settings → See all settings → General
  2. Signature → Create new, give it a name
  3. Paste, then Save changes at the bottom

Outlook

  1. New Outlook / web: Settings → Account → Signatures
  2. Classic Windows: File → Options → Mail → Signatures
  3. New signature, paste, Save

Apple Mail

  1. Mail → Settings → Signatures
  2. Select your account, click +
  3. Untick “Always match my default message font”, then paste

Images can show as “?” in the settings window. They appear in sent mail.
